# React Tetris Clone

A custom Tetris clone built completely from scratch using React. This project was developed with a strong focus on clean software architecture (DRY principles), disciplined version control practices, and just trying out new things.


---

## 🚀 Features

* **Classic Tetris Gameplay:** Fully functional game mechanics including block rotation, harddrop, collision detection, line clearing, scoring system, and progressive speed difficulty.

  
* **Audio Integration:** Dynamic sound effects triggered by in-game actions.

---

## 🛠️ Tech Stack & Architecture

* **Frontend:** React (Hooks, Functional Components, and State Management)
* **Clean Code & DRY:** Strict adherence to the *Don't Repeat Yourself* principle. 
* **Conventional Commits:** The repository maintains a highly structured version history following the `type: change` pattern (e.g., `feat: add sound effects for line clears` or `refactor: optimize collision detection logic under DRY`).
